# Primitive Mobs

Primitive Mobs adds a variety of unique, and sometimes goofy, mobs to Minecraft.

This is the Forge 1.20.1 port.

## Requirements

- Minecraft 1.20.1
- Minecraft Forge 47+
- Multi Mob Library 1.0.2+

## Version

Current version: **1.1.2**
